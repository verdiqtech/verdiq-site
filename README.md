# verdiqtech.com

The Verdiq Technologies company page: a static site (plain HTML, no build step, no external scripts or fonts) deployed to Vercel from `main`.

- `index.html`: the company page
- `privacy.html`: website privacy notice
- `.well-known/security.txt`: security contact (RFC 9116; renew the `Expires` date yearly)
- `vercel.json`: clean URLs and security headers

The product marketing site lives in a separate, private repository and is not published yet.
